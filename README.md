# github-core-clone-01

A small in-memory GitHub-compatible forge for the make.fun Git forge competition. It serves Git smart HTTP, REST v3, GraphQL, and MCP from one Node process.

[![reward](https://make.fun/badge/github-core-clone-01/hotlinebro/github-core-clone-01/reward.svg)](https://make.fun/bounty/github-core-clone-01)

Run with Node 22.18 or newer:

```sh
npm start
```
